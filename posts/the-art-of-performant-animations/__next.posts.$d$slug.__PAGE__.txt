5:Ta0b,<p>Animation is not decoration. When done right, motion communicates hierarchy, guides attention, and creates a sense of physicality in digital space. When done wrong, it's a battery-draining, accessibility-breaking nightmare.</p>
<h2>The 60fps Imperative</h2>
<p>Human perception is tuned to detect motion irregularities. A dropped frame at 60fps creates a visible stutter that registers as <em>jank</em> — a subconscious signal that something is broken.</p>
<p>The rules are simple:</p>
<ol>
<li><strong>Animate only <code>transform</code> and <code>opacity</code></strong> — these are GPU-composited</li>
<li><strong>Avoid layout-triggering properties</strong> — <code>width</code>, <code>height</code>, <code>margin</code>, <code>padding</code></li>
<li><strong>Use <code>will-change</code> sparingly</strong> — it's a hint, not a magic wand</li>
<li><strong>Prefer CSS transitions over JavaScript</strong> when possible</li>
</ol>
<h2>The FLIP Technique</h2>
<p>FLIP (First, Last, Invert, Play) is the gold standard for layout animations:</p>
<pre><code class="language-javascript">// First: record initial position
const first = element.getBoundingClientRect();

// Last: trigger the layout change
element.classList.add('expanded');
const last = element.getBoundingClientRect();

// Invert: apply a transform to restore original position
const deltaX = first.left - last.left;
const deltaY = first.top - last.top;
element.style.transform = `translate(${deltaX}px, ${deltaY}px)`;

// Play: animate to final position
requestAnimationFrame(() => {
  element.style.transition = 'transform 0.3s ease';
  element.style.transform = '';
});
</code></pre>
<p>This technique lets you animate between any two layout states at 60fps because the actual animation only uses <code>transform</code>.</p>
<h2>Respecting User Preferences</h2>
<p>Not everyone wants motion. The <code>prefers-reduced-motion</code> media query is essential:</p>
<pre><code class="language-css">@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
</code></pre>
<p>This isn't optional — it's an accessibility requirement.</p>
<h2>Motion as Language</h2>
<p>The best animation systems create a consistent motion language. Spring physics feel natural. Ease-in-out curves suggest physical weight. Stagger delays create rhythm and hierarchy.</p>
<p>Invest in your animation system the same way you invest in your type scale or color palette. Motion is a first-class design primitive.</p>
